# 苏麻离青 · 产品设计2 综合设计图册（线上展陈）

《产品设计2》课程作业的综合展示网站。围绕**汽车内饰 CMF、汽车人机界面、汽车周边产品功能结构**三大研究单元，
以矿物钴蓝「苏麻离青」为主题，将丝路大漠暖金与青花瓷深蓝注入瑞风 RF8 智能座舱。

## 两种交付形态

- **`苏麻离青.html`** — 单文件版：CSS / JS / 全部图片均以 base64 内联，双击即可离线打开，便于交作业 / 拷贝。
- **多文件版** — `index.html` + `assets/`，便于二次编辑与网页托管。

单文件由多文件构建而来（`index.html` + `assets/css` + `assets/js` + `assets/*` 内联）。

## 本地预览（多文件版）

```bash
python3 -m http.server 8000   # 打开 http://localhost:8000
```

## 目录结构

```
苏麻离青.html          单文件自包含版（可直接发送 / 离线打开）
index.html            多文件版主页面
assets/css/style.css  样式：深墨底 + 米白内页（图2 编辑杂志风）
assets/js/main.js     交互：自定义光标、玻璃倾斜、翻页书、灯箱
assets/cmf/           CMF 12 帧图版
assets/img/           封面、丝路长卷、大漠、材质板
```

## 设计说明

- **视觉**：深墨底 `#16171b` + 米白内页 `#f0eadd`，细框 / 竖排巨字 / 星号点缀（严格参考图2）
- **配色点缀**：苏麻离青 `#39608c` · 大漠暖金 `#b3873f` · 朱砂 `#a23f2e`
- **字体统一**：英文 Fraunces（高对比衬线）+ 中文思源宋体 + 小字 Inter
- **交互**：Apple 液态玻璃卡片、自定义光标、Hero 视差、单页翻页书
- **首页**：直接用瑞风 RF8 封面大图，标题 / 课程 / 指导 / 成员文字排版其上
- **扉页**：前言 + 作品整体概述
