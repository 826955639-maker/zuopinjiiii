# 苏麻离青 · 产品设计2 综合设计图册（线上展陈）

《产品设计2》课程作业的综合展示网站。围绕**汽车内饰 CMF、汽车人机界面、汽车周边产品功能结构**三大研究单元，
以矿物钴蓝「苏麻离青」为主题，将丝路大漠暖金与青花瓷深蓝注入瑞风 RF8 智能座舱。

## 当前进度

| 单元 | 内容 | 状态 |
| --- | --- | --- |
| 一 · CMF 研究与设计 | 苏麻离青 · 瑞风RF8 内饰 CMF（Pencil Studio，12 帧图版） | ✅ 已就绪 |
| 二 · 人机界面研究 | 调研综述 / 要素拆解 / 设计成果 | ⬜ 占位待填充 |
| 三 · 功能结构研究 | 产品选定 / 覆盖件分析 / 结构拆解 / 尺寸评价 | ⬜ 占位待填充 |
| 四 · 课程总结 | 课程回顾 / 创新点 / 感悟致谢 | ⬜ 占位待填充 |

> 把人机界面、功能结构、课程总结的资料（图片 / PDF / 文字）发来，即可按现有「苏麻离青」视觉风格填入对应区块。

## 本地预览

纯静态站点，无需构建：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 目录结构

```
index.html            主页面（单页滚动 + 灯箱）
assets/css/style.css  样式：宣纸米 + 苏麻离青 + 大漠暖金
assets/js/main.js     交互：滚动渐显、图版灯箱、导航高亮
assets/cmf/           CMF 单元 12 帧图版（由 CMF 设计方案 PDF 渲染）
```

## 设计说明

- **配色**：宣纸米底 `#f3ecdd` · 苏麻离青 `#1d3f6e` · 大漠暖金 `#b3873f` · 墨字 `#23252a`
- **字体**：标题 Noto Serif SC，正文 Noto Sans SC，点睛 Ma Shan Zheng（毛笔体）
- **版式**：编辑式 / 美术馆展陈风格，参考给定视觉稿，结合青花瓷主题
